# Генератор Reset

Запуск из корня проекта (`c:/goprojects/yp-shorter`):

```sh
go run ./cmd/reset
```

Добавьте комментарий непосредственно перед объявлением структуры:

```go
// generate:reset
type Buffer struct {
    Text string
    Items []string
    Counts map[string]int
    Next *Buffer
}
```

Также поддерживаются и комментарии перед
структурами внутри группового объявления `type (...)`.
Методы одного пакета записываются в его `reset.gen.go`.

Правила сброса:

- числа, строки и логические значения получают нулевые значения;
- слайсы обрезаются до нулевой длины с сохранением памяти;
- мапы очищаются через `clear`;
- ненулевые указатели сохраняются, сбрасываются значения по ним;
- у вложенных структур вызывается `Reset()`, если он есть, иначе они
  остаются без изменений;
- элементы массивов сбрасываются по тем же правилам;
- интерфейсы, каналы и функции получают `nil`;
- вызов метода у `nil`-получателя безопасен.

Именованные типы и псевдонимы поддерживаются. У обобщённых структур
поддерживаются, например, поля `[]T` и `map[string]T`; непосредственное поле
типа `T` отклоняется с диагностикой, поскольку единое правило сброса для
произвольного параметра типа не определено.

Обход использует пакеты текущего модуля по шаблону `./...` с текущими
ограничениями сборки. Тестовые файлы, `testdata`, `vendor` и отдельные вложенные
модули не обрабатываются. Исходные пакеты должны проходить проверку типов:
если изменение структуры сделало старый `reset.gen.go` некорректным,
удалите этот сгенерированный файл перед повторным запуском.

Генератор не перезаписывает чужой `reset.gen.go` и сообщает о конфликте
с вручную объявленным методом `Reset`. Повторная генерация детерминирована;
после удаления всех меток из пакета собственный сгенерированный файл удаляется.
Циклические ссылки между объектами не отслеживаются: рекурсивные вызовы
`Reset()` предполагают отсутствие циклов в сбрасываемом графе объектов.

Проверка:

```sh
go test ./cmd/reset -count=1
```

Тесты создают временный модуль, генерируют методы, затем компилируют и
выполняют их через `go test`, проверяя также сохранение указателей,
памяти слайсов и мап.
